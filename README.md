# Personal Profile

เว็บ Personal Profile แบบ static (HTML + CSS + JavaScript) สำหรับ System Engineer ที่กำลังเปลี่ยนสายสู่ DevOps

## Sections
Hero · About · Skills · Projects · Contact

## โครงสร้าง
```
└── profile.html   (HTML + CSS + JS ในไฟล์เดียว)
```

## วิธีรัน
เปิด `profile.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## แก้ไขข้อมูล
แก้ array `skills` และ `projects` ในแท็ก `<script>` ของ `profile.html`
